# Gravity Hand Gesture 🖐️🌌

A real-time webcam-based hand gesture project that simulates gravity interaction using computer vision.

This project detects hand movements through a webcam and applies gravity-like effects based on gesture input.

---

## 🚀 Overview

Gravity Hand Gesture is a computer vision project that tracks hand gestures in real-time using a webcam.  
Based on the detected gestures, gravity-based interactions are simulated dynamically on screen.

The project demonstrates practical implementation of real-time vision processing and interactive physics simulation.

---

## ✨ Features

- Real-time hand detection via webcam
- Gesture recognition system
- Gravity simulation logic
- Smooth motion tracking
- Interactive visual feedback

## ⚙️ How It Works

1. Webcam captures live video feed
2. Hand landmarks are detected
3. Gesture is analyzed
4. Gravity effect is triggered based on gesture input
